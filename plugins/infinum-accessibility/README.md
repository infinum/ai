# infinum-accessibility

Two skills that cover an accessibility audit from design to delivery.

| Part | Skill | What it does |
|---|---|---|
| 1 | [`figma-design-accessibility-audit`](skills/figma-design-accessibility-audit/) | Audit Figma designs against the Infinum Accessibility Guidelines. Creates a Figma file with a filled-in checklist with annotated issues, linked to the guidelines, and notes for developers. |
| 2 | [`accessibility-audit-report`](skills/accessibility-audit-report/) | Build or update a web or mobile accessibility audit report (Google Doc) and generate a matching VPAT/ACR on request. |

Install with `/plugin install infinum-accessibility@infinum-ai`.
